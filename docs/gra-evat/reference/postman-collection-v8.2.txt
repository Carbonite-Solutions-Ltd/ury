COLLECTION DESCRIPTION
####################################################################################################
This document (GRA E-VAT API Documentation or E-VAT API Documentation or VCIS/VSDC API Documentation) describes the API specification for the integration of Taxpayer systems to the Commissioner-General's Electronic Invoicing Systems (E-VAT).

OVERVIEW
The following specific requirements are for the systems to communicate with E-VAT VCIS, the Certified Invoicing System to be used together with a Virtual Sales Data Controller (VSDC).

Data Flow Diagram

AUTHENTICATION
This API requires an Authentication in the Request Header
Example: "security_key": "1234567890987UIEGRTEIIIWOWPPWOOW"

The security key is a static value that will be expected across all endpoints that data is sent, whenever a request is made.

DATA FORMAT
E-VAT API Receives accepts payloads in any of the formats below:

JSON

XML

DEPLOYMENT TYPE
Taxpayers are allowed to choose between the cloud deployment and the On-Prem deployment.
Cloud Deployment is where GRA hosts the software that stamps your E-VAT invoices
On-Prem Deployment is where the taxpayer provides a server, either within their network (preferably) or a dedicated private cloud server.
The EVAT Team recommends for taxpayers that issue huge number of invoices within a day to opt for the On-Prem Deployment

ON-PREM DEPLOYMENT MINIMUM HARDWARE SPECIFICATION

HDD: 500GB

RAM: 8GB

OS: Windows Server 2019 + / Windows 10 +

LEVY MAPPING

levyAmountA : NHIL 2.5 %

levyAmountB: GETFL 2.5 %

levyAmountC : COVID 1% (Applies to invoice dates before 1st January 2026)

levyAmountD : CST 5%

levyAmountE : TOURISM LEVY 1%

FOLDER /INVOICE REFUNDS
====================================================================================================
--- DESCRIPTION ---
This includes Partial and Full Refunds

FULL REFUND

A Full Refund refers to a situation where a customer receives complete reimbursement of the total amount they paid for a product or service. It means that the seller or service provider returns the entire purchase price to the customer.

PARTIAL REFUND
A Partial Refund refers to a situation where a customer receives a refund for only a portion of the total amount they paid for a product or service.

A Credit Note, also known as a Credit Memo, is a document issued by a seller or service provider to a customer as a form of credit or refund. It is typically provided when there is a need to rectify a previous transaction, such as returning goods, resolving a billing error, or providing compensation for a service issue.
